Discord bot — `/wowai` queries from inside Discord. Casual-query surface that doesn't require the addon+desktop pattern.

**Status**: empty placeholder. Belongs to Phase 3 of the build plan, NOT Phase 1.

**Why this exists at all**: WoW players live in Discord. A bot that answers "where do I get Invincible's Reins" with attribution back to everloot.app is a viral acquisition channel.

**Not now**: every line of code here is a distraction from shipping Phase 1.
